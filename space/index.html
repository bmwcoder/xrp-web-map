    How to read this preview

    Connections are lines. Each line means a public source ties two entities in the way the label says. Size is how many connections an entity has. A connection is not a partnership, control, or wrongdoing unless the label and the source say so.

    Adoption is a separate mark on a connection: supports XRP or Ripple payment-rail adoption, is not about that question, or contradicts it. Both directions are drawn. Filtering to “supports adoption” hides the rest; it does not turn those connections into adoption.

    Grades rate the source, not the person. A is a primary or official record. B is reputable reporting. C is an unverified claim. X was checked and found false.

    The view opens on key connections, the smaller set marked in the public graph. “All connections” draws every link in the file. Home clears a selection and returns to key connections.

    Drag to orbit, scroll or pinch to zoom, tap a point or search to inspect sources. Arrow keys orbit when the galaxy is focused. Slash focuses search. Escape closes this dialog, a tour, then the details.

    Pause motion stops the slow orbit, the star shimmer, and the fly-to glide. Reduced-motion settings start paused. If WebGL is missing, search and the written record stay available.

    Data is the public graph.json, the same file as the live map. On this host it is read from the copy beside the page; if that file is missing, the page requests xrpmap.org directly. Selecting an entity draws its real connections in a nearby shell so the names fit on screen. That arrangement is not a new relationship, and Home restores the galaxy. Positions are not the flat map’s x/y coordinates, and this is not a video.

    The live map is unchanged. This page asks crawlers not to index it. That is not access control.
